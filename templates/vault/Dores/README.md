# Dores

Problemas observados, cada um com evidência. Formato inspirado no nugget de atomic research: uma observação, uma evidência, um contexto.

- **Template:** `dor`
- **Estados:** `capturada → confirmada → agrupada | descartada`
- **Regra:** sem `evidencia`, a dor não sai de `capturada`.
- **Vira:** insumo de um ou mais [[Insights/README|Insights]] (estado `agrupada`).

Pendências desta pasta aparecem no [[Painel]].
