# Diário

## Convenção de nome de arquivo

As notas diárias devem seguir a convenção: `YYYY-MM-DD.md`

Exemplo: `2026-10-21.md`

## Fluxo padrão

O registro de diário segue o fluxo **pós-rito**: captura realizada após o encerramento do dia, não durante.

Ao criar uma nova nota diária usando o template `diario`, o bloco Dataview carrega automaticamente as pendências (tarefas não concluídas) de dias anteriores, permitindo o carry-over e continuidade do trabalho.
