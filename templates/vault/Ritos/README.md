# Ritos

Encontros recorrentes onde dores surgem e decisões acontecem. Cada rito tem uma hub note nesta pasta, que lista os seus encontros e os itens em aberto com `rito_origem` apontando para ela.

## Encontros

Cada ocorrência de um rito é uma nota em `Encontros/`, criada a partir do template `encontro`, com o nome `YYYY-MM-DD-<rito>.md` (ex.: `2026-10-23-people.md`). O campo `rito:` liga o encontro à hub.

Os encontros ficam numa pasta única, não uma por rito: a pasta indica o tipo da entidade, e o rito é um atributo.
