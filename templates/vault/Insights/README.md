# Insights

Hipóteses de causa que ligam uma ou mais dores. Um insight amadurece no próprio lugar: não existe pasta separada de "análise".

- **Template:** `insight`
- **Estados:** `hipotese → evidenciado → validado | refutado`
- **Nasce de:** revisão semanal ou aplicação de uma técnica do Kit (`.catalisa/kit/tecnicas.csv`).
- **Vira:** [[Iniciativas/README|Iniciativa]] quando `validado`.

Pendências desta pasta aparecem no [[Painel]].
