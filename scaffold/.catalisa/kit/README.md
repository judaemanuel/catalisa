# Kit

Práticas reutilizáveis para conduzir a revisão semanal e as transições de estado. São consumidas principalmente pela camada de IA, mas também podem ser lidas e usadas diretamente.

| Arquivo | Uso |
|---|---|
| `tecnicas.csv` | Técnicas de análise e ideação. A coluna `transicao` indica onde cada uma se aplica: `dor-insight` (causa-raiz), `insight-iniciativa` (gerar melhoria), `iniciativa-output` (pressionar a proposta e comunicar). Registre o `id` usado no campo `tecnica` do Insight. |
| `convergencia.md` | Como estreitar e decidir depois de divergir (agrupar dores, priorizar iniciativas). |
| `posturas.md` | Quem pensa e quem facilita: facilitador, parceiro ou gerador. |
