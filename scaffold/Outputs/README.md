# Outputs

Material para uma audiência específica (gestão, cliente, board do grupo), composto a partir de insights e iniciativas. Amadurece no próprio lugar até ser apresentado.

- **Template:** `output` (só frontmatter; o corpo é livre até surgirem padrões)
- **Estados:** `rascunho → revisao → pronto → apresentado`
- **Rastreabilidade:** `fontes` lista as notas que sustentam o material; `rito_destino` indica onde será apresentado.

Pendências desta pasta aparecem no [[Painel]].
